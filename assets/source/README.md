# Editable game artwork

Keep editable Aseprite files, Tiled projects, source layers, and provenance/license notes here. Export only runtime assets to `public/game/` or `public/products/`.

`ui-concepts/sidequest.png` is the visual target for the village and HUD. The current village artwork is procedural pixel art in `src/game/art/` (tile-map terrain, building/prop sprites, bitmap font). Raster layers, sprite sheets, and generated or hand-edited artwork may replace or extend it; keep their editable sources and provenance here.
