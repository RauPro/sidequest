# Editable game artwork

Keep editable Aseprite files, Tiled projects, source layers, and provenance/license notes here. Export only runtime assets to `public/game/` or `public/products/`.

The existing root `Reference Image` guided composition and mood only. The village artwork is procedural 3/4-view pixel art, original, and lives in `src/game/art/` (tile-map terrain, building/prop sprites, bitmap font); there is no raster source.
